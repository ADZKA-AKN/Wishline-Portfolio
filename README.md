# WISHLINE — Tailwind Version

Versi website Wishline yang style utamanya sudah dipindahkan dari CSS custom ke Tailwind CSS utility classes.

## Struktur

- `index.html` — seluruh layout + Tailwind classes
- `script.js` — mobile menu + scroll progress
- `README.md`

## Menjalankan

Buka `index.html` langsung di browser.

Versi ini memakai Tailwind CSS melalui CDN, jadi tidak perlu install Node.js atau dependency untuk mencoba hasilnya.

## Jika ingin project Tailwind profesional

Untuk production, Tailwind CDN bisa dipindahkan ke setup Tailwind CLI/Vite/Next.js sehingga class dapat diproses dan CSS final lebih kecil.
